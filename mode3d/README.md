# 3D posing

The editor defaults to 2D and loads Three.js 0.164.1 only when 3D is selected. The mannequin is generated from primitives and contains no external model asset. Move the hips, hands or feet; use Rotate for other joints and turn on Finger joints to select individual finger bones. Drag empty space to orbit, scroll to zoom, and adjust Field of view for perspective. Presets start in a planar pose and can then be posed in 3D. The 3D state is stored separately from the existing 2D pose and history.

The BODY_25 + hands guide projects 3D joint positions through the same square camera used by the depth export. When an endpoint is outside near/far, that point and connected segments are omitted; a joint hidden by a body surface is still shown. The high-angle head outline is the convex hull of the projected vertices of the polygonal head, omitted if any vertex is clipped. 3D hand shape/contact prompt descriptions are omitted because 2D projection alone cannot establish those properties. Limb depth text states relative distance without asserting a sole or palm orientation.

Depth is a linear camera-space Z image: near bound=255, far bound=1, background=0, with antialiasing at boundaries. The mapping range is recomputed from conservative depth bounds of all mannequin ellipsoids intersecting the camera near/far planes; it can include geometry off-screen or occluded. Different exports may map the same distance to different gray values. Export 3D state alongside depth to record the camera and mapping range needed to interpret that image. Depth is a separate export and is not sent to an image provider.
